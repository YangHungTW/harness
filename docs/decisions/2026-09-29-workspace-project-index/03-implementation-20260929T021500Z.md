## Bug found by the real-workspace dry run
The first `propose.sh` tagged 8 of 11 real `~/Projects` repos as `pii`.

**Cause:** `find ... -print0 | xargs -0 grep -q`. When find matches nothing, BSD xargs runs no command and still exits 0, so the pipeline read as "matched".

**Fix:** `any_match()` now requires `grep -l` to actually print a filename. The dependency check (`live-money`) used the same pattern and got the same fix.

The fixture passed before the fix because every fixture project happened to have schema/manifest files, or lacked them in ways that didn't expose the bug. Two regression assertions were added:
- a project with no schema/dependency/deploy files gets `risk: []`
- `repo-a` with a `students` table gets `pii`

The first would fail against the old script.
